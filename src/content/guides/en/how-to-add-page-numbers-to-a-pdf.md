**Short answer:** Open [Add page numbers](/add-page-numbers), choose a style and position, and download the file; tick **Skip the first page (cover)** to leave a cover unnumbered. The numbers are drawn on the page itself, unlike page labels, which only change what a PDF reader shows.

A long document without page numbers is hard to discuss: "see the table on page 14" only works when page 14 says it is page 14. Many PDFs, especially ones merged from several files or scanned from paper, have no numbers at all. This guide explains how to add them, how to handle covers and special cases and how this differs from the page labels a PDF reader shows.

## How to add page numbers with LeafLock

The numbers are written into the PDF by your browser, on your device. The document is not uploaded.

1. Open [Add page numbers](/add-page-numbers) and choose your file.
2. Choose the style, position and size. The preview shows how the numbers will look.
3. Set any options, such as skipping the cover.
4. Add the numbers and download the file.

## Where the numbers go

Put them at the top or bottom, and on the left, center or right. You can also set the text size, the color and the distance from the edge. Bottom center suits most documents, and bottom outside corners suit printed double-sided pages, where the number stays near the edge of each page.

Make sure the numbers do not collide with an existing footer. If they do, increase the distance from the edge, or pick another corner.

## Skipping the cover page

Tick **Skip the first page (cover)**. Page 2 then gets the first number, which is 1 unless you change it. That gives you a cover with no number and the first inside page marked 1.

## Starting from a different number

Set **First number** to the number the first numbered page should get. That is useful for a chapter that continues from another file, such as an appendix that begins at page 41.

## "Page 1 of 10"

Pick that style, or choose **Custom** and type your own text with the placeholders shown under the field. The total is the last number used, so it allows for skipped pages. If you skipped the cover of a 10-page document, the total reads 9, because 9 pages were numbered.

## Numbering only some pages

Choose **Chosen pages** and type the pages, for example `3-12`. The numbers run in order across the pages you pick, so the first chosen page gets the first number.

## Page numbers versus page labels

Add page numbers **draws visible text** on the page. [Add page labels](/add-page-labels) sets the number your PDF reader shows in its own page box and thumbnail strip, and leaves the page itself alone. Use numbers when the page must show a number on paper, and labels when the reader's navigation should match the printed numbers, such as roman numerals for a preface. Many documents use both. See [how to set roman numerals and custom page labels in a PDF](/guides/how-to-set-page-labels-in-a-pdf).

## Before you number

- **Remove unwanted pages first** with [Remove pages](/remove-pages), so numbers are continuous.
- **Reorder** with [Organize PDF](/organize-pdf), because numbering follows the current order.
- **Merge** files first with [Merge PDF](/merge-pdf), if you want one continuous sequence.

For legal discovery, where every page needs a unique reference across files, use [Bates numbering](/bates-numbering) instead; see [how to add Bates numbers to a PDF set](/guides/how-to-add-bates-numbers-to-pdfs).

## Check the result

Look at the first numbered page, a page in the middle and the last page. Make sure no number sits on top of existing text, and that landscape pages show the number where you expect.

## Summary

1. Choose position, style and size, and watch the preview.
2. Skip the cover, or start from any number.
3. Number a chosen range if needed.
4. Do your merging, deleting and reordering before numbering.
