**Short answer:** [Organize PDF](/organize-pdf) shows every page as a thumbnail, so in one view you can reorder pages by dragging, rotate them, remove them, add a blank page and combine several PDFs. You see the finished order before you save.

A PDF rarely comes out in exactly the order you need. A scan fed in upside down, an appendix that should come first, a page you want to repeat, or two documents that should become one. Organize PDF handles all of these in a single view, so you do not have to chain four tools. This guide explains how to use it well and what the edges are.

## What you can do in one view

[Organize PDF](/organize-pdf) shows every page as a thumbnail. In that one screen you can:

- **Reorder** pages by dragging them, or with the arrow buttons under each page.
- **Rotate** a page that came in sideways or upside down.
- **Remove** a page, and bring it back again with the button under it.
- **Add a blank page**, which goes at the end and matches the size of the last page.
- **Combine** pages from more than one PDF by adding several files.

Because it is all in one place, you can see the finished order before you save anything.

## How to reorder pages with LeafLock

The page previews and the final file are both made in your browser, so your files stay on your device.

1. Open [Organize PDF](/organize-pdf) and choose your PDF (or several).
2. Drag pages to where they belong. On a phone or tablet where dragging is awkward, use the arrow buttons to move a page earlier or later.
3. Rotate or remove pages as needed.
4. Select the save button and download the new PDF.

## Working on a touch screen

Dragging thumbnails on a touch screen can be fiddly, especially with many pages. The arrow buttons under each page do the same job and are more precise. For a long document, move pages in several short steps rather than one long drag.

## Combining pages from several PDFs

Add more than one file and all their pages appear together in one list. You can interleave them, move a page from the second file to the front, or drop pages you do not need before saving. If you only want to join files end to end, [Merge PDF](/merge-pdf) is the shorter route, and [how to merge PDFs without uploading them](/guides/merge-pdf-without-uploading) covers the details.

## Undoing mistakes

A removed page can be restored with the button under it. **Undo all changes** puts every page back the way it was when you added the files. Nothing is final until you download, and the original file is never changed.

## Does it change quality?

No. Pages are copied as they are, and rotating only changes their orientation setting, so nothing is re-compressed and text stays sharp and selectable.

## Common jobs

- **Fix a scan fed in the wrong way round.** Rotate the affected pages, or use [Rotate PDF](/rotate-pdf) if the whole file is turned.
- **Put the signature page first.** Drag it to the top.
- **Insert a section divider.** Add a blank page, then move it where the divider belongs.
- **Reverse a document scanned back to front.** The [reverse pages](/reverse-pdf-pages) page opens this tool already set to reverse.
- **Rearrange for a presentation or handout.** Reorder here, then print several per sheet with [multiple pages per sheet](/multiple-pages-per-sheet).

## What to check afterwards

Scroll through the result once. Check that the first and last pages are right, that rotated pages read upright and that no page is duplicated by accident. If the document had printed page numbers, they will no longer be in order. Add new ones with [Add page numbers](/add-page-numbers), or set what your reader shows with [Add page labels](/add-page-labels).

## What does not carry over

As with any operation that copies pages into a new file, features that depend on the whole document, such as bookmarks and links between pages, are not carried across. If your document depends on a clickable table of contents, rebuild it after reordering.

## Summary

1. One view handles reordering, rotating, removing and adding blank pages.
2. Use the arrow buttons if dragging is awkward on your device.
3. Undo restores removed pages and the whole starting state.
4. Pages are copied without recompression; page numbers and links need a second look.
