**Short answer:** Open [Bates numbering](/bates-numbering), add your files in the order they should be numbered, set the prefix, digits and starting number, then stamp and download them. The numbers run on across every file, which ordinary page numbers do not.

When a case involves thousands of pages across many files, "page 3 of the third PDF" is not a usable way to cite anything. Bates numbering gives every page a unique identifier, so any page can be named, found and referred to without ambiguity. This guide explains the format, how to stamp it on a set of PDFs and what to check before the numbered set goes out.

## What a Bates number is

A unique label stamped on every page of a document set. Usually a short prefix followed by a zero-padded number, such as `ABC000001`. The label identifies the page regardless of which file it lives in. Law firms use it in discovery and many other fields use it for audits, due diligence and records production.

## Why a dedicated tool

Ordinary [page numbers](/add-page-numbers) restart in every file. Bates numbers must continue across files, so the second PDF begins where the first ended. [Bates numbering](/bates-numbering) does that: the order the files are listed in is the order they are numbered in.

## How to add Bates numbers with LeafLock

Bates numbering is a Practice tool and runs in your browser. Every file is stamped on your device and never leaves it, which matters when the documents are privileged or confidential.

1. Open [Bates numbering](/bates-numbering) and add your files.
2. Put them in the order you want them numbered.
3. Set the prefix, digits, starting number, suffix and position.
4. Stamp the files and download them.

## The settings

- **Prefix** comes before the number: a matter or case code, for example.
- **Digits.** The number is padded with leading zeros to this width. 6 is common for case files, giving 000001 to 999999.
- **Starting number.** Use it to continue an earlier production, so the next batch begins where the last one stopped.
- **Suffix** goes after the number, such as `-CONF` for confidential pages.
- **Position.** Choose the corner or edge, the text size, color and distance from the edge. The bottom right is conventional, and it should avoid existing footers.

## Planning your production

1. **Finish editing first.** Remove, reorder and merge pages before numbering. Numbering after changes avoids gaps and duplicates.
2. **Redact before stamping**, if pages need it. Use [Redact PDF](/redact-pdf), and see [how to redact a PDF properly](/guides/redact-pdf-properly).
3. **Decide the order** of files, because it determines every number.
4. **Keep a log** of which number range maps to which file. The tool numbers; the index is yours to keep.

## Do not renumber after sending

Once a set has gone out, adding or removing a page breaks every reference that follows. If you must change something, add a replacement under a new range, and record why.

## Checking the result

Open a file from the middle of the set and check the number is right, and that the last page of one file leads into the first page of the next. Look at pages with unusual sizes or rotation, where the stamp could land somewhere unexpected.
