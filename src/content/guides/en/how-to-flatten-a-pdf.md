A filled-in PDF form is still a form. Anyone who opens it can change the answers. A PDF with comments and highlights is still a working document, with notes that can be edited or deleted. Flattening finalizes it: what you see becomes part of the page. This guide explains what flattening changes, when to use it and, importantly, what it does not do.

## What flattening does

It turns form fields into ordinary page content, so the answers stay visible but cannot be edited. By default, comments, highlights, stamps and drawings are flattened too. After flattening, the file looks the same and behaves like a fixed document.

## How to flatten with LeafLock

Flattening happens in your browser, so the file is not uploaded.

1. Open [Flatten PDF](/flatten-pdf) and choose a PDF with form fields or annotations.
2. Choose whether to flatten annotations as well. It is on by default.
3. Flatten and download the copy.

If the PDF has no form fields or annotations, you are told there is nothing to flatten.

## Links and comments

Links keep working. Comment pop-up notes are removed, since their text cannot be shown on the page. If the words in those notes matter, copy them out first or print the comments with the document before flattening.

## When to flatten

- **Before sending a completed form** so the recipient receives answers that cannot be altered by accident.
- **Before archiving** a final version.
- **Before sharing a reviewed document** where everyone should see the highlights as part of the page.
- **When a viewer displays fields badly.** Some readers show form fields oddly or let them overwrite; flattening gives consistent output.
- **Before a printing workflow** that mishandles interactive content.

## When not to flatten

If someone still needs to edit the fields, do not flatten. You cannot undo flattening in the flattened copy, but your original is not changed, so keep it. Name the flattened file clearly, for example `form-final.pdf`.

## Flattening is not redaction

It does not remove sensitive information. The content stays in the file as ordinary text and images. To remove information for good, use [Redact PDF](/redact-pdf), and read [how to redact a PDF properly](/guides/redact-pdf-properly).

## Flattening versus removing annotations

[Remove annotations](/remove-annotations) deletes comments and highlights so they are gone from the page. Flattening paints them in so they stay visible. Choose by whether the markup should still be seen. See [how to remove comments and annotations from a PDF](/guides/how-to-remove-comments-and-annotations-from-a-pdf).

## The form is not filled in yet

Fill it in first with [Fill PDF form](/fill-pdf-form). That tool can also lock the answers in when you save, so you may not need to flatten separately. See [how to fill in a PDF form and lock your answers](/guides/how-to-fill-in-a-pdf-form).

## Where flattening fits in a signing flow

1. Fill the form.
2. Sign it with [Sign PDF](/sign-pdf); see [how to sign a PDF without printing](/guides/how-to-sign-a-pdf-without-printing).
3. Flatten the finished document.
4. Protect or send it.

## Check the result

Open the flattened file. Fields should show their values but not respond to clicks. Check that nothing important was a comment that has now disappeared.

## Summary

1. Flattening turns fields and markup into fixed page content.
2. Links stay; comment pop-up notes go.
3. It cannot be undone in the copy, so keep the original.
4. It does not remove sensitive information.
