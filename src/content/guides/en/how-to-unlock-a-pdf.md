**Short answer:** [Unlock PDF](/unlock-pdf) removes an open password if you type it, and removes restrictions on printing, copying or editing without one. It cannot guess or crack a password you do not have.

A password on a PDF is useful until the day you have to type it every time, or until another tool refuses to work on a locked file. If the PDF is yours, or you have been given the right to change it, removing the password is a routine job. This guide explains what unlocking does, which password to use and what it cannot do.

## Two kinds of protection

PDFs can carry two different kinds of lock, and they behave differently.

- **An open password** is needed to view the file at all. Without it, nothing opens.
- **Restrictions** limit what you can do after opening: printing, copying text or editing. The file opens without a password, but some actions are blocked.

[Unlock PDF](/unlock-pdf) handles both.

## What you must know

If the PDF needs a password to open, you need that password. This tool cannot guess or crack it. If it only limits printing, copying or editing, it unlocks without one.

## How to unlock with LeafLock

The password is used only by your browser to decrypt the file on your device. Neither the password nor the PDF is uploaded.

1. Open [Unlock PDF](/unlock-pdf) and choose your file.
2. If asked, type the password.
3. Unlock and download.

## Which password to type

The password you use to open the PDF, or its permissions password if it has one. If you are unsure which you have, try the one you were given with the file.

## What you get

A copy without the password, with the same pages, text and images. Nothing about the content changes.

## Only unlock files you may unlock

Only unlock files you own or have permission to change. A restriction exists because the author wanted it. Removing a password from a document that belongs to someone else, or that you received under conditions, may breach those conditions or the law. If you are unsure, ask the owner.

## Common reasons to unlock

- **You want to use another tool.** Many operations, such as merging, splitting, OCR and conversion, need to read the file, so remove the password first.
- **You are tired of retyping it.** Your own archive documents do not need one on every copy.
- **You inherited a file with restrictions** and have the right to change it.
- **You want to re-protect it with a new password.** Unlock, then [Protect PDF](/protect-pdf); see [how to password-protect a PDF](/guides/how-to-password-protect-a-pdf).

## Forgotten passwords

If you do not have the password and the PDF needs it to open, this tool cannot help, and no honest tool can promise to. Try to recover the password from where it came from: the sender, your password manager or the account that generated the file.

## After unlocking

1. Open the result and confirm it opens without prompting.
2. Delete or secure the unlocked copy if the content is sensitive, because it now has no protection.
3. Re-protect it if you only wanted to change the password.

## Works on a phone

It works in a modern browser on phones, tablets and computers, with nothing to install.

## Summary

1. Unlocking needs the password for an open-password file; restrictions unlock without one.
2. The password and file stay on your device.
3. Only unlock files you are allowed to.
4. The unlocked copy is unprotected; handle it accordingly.
