Cropping a PDF trims the visible area of its pages: wide margins on a scanned page, a header and footer you do not want in a handout, or a single figure cut out of a full page. It is quick and it does not lower quality. It also has a catch that matters if the document is sensitive, and we start with that.

## Cropping hides; it does not delete

When you crop a PDF page, the content outside the box is not removed. It is still in the file, hidden from view. Other PDF software can bring it back by resetting the page box, and anything hidden can still be found by selecting text or searching.

That is fine for tidying margins. It is not fine for removing information, such as a name in a margin or a figure you should not share. For that, use [Redact PDF](/redact-pdf), and read [how to redact a PDF properly](/guides/redact-pdf-properly).

## How to crop a PDF with LeafLock

Cropping is done in your browser, and the file never leaves your device.

1. Open [Crop PDF](/crop-pdf) and choose your file.
2. Drag the crop box on the preview, or type how much to trim from each side as a percentage of the page.
3. Choose which pages the crop applies to.
4. Save and download.

## Choosing which pages to crop

You do not have to crop everything. You can apply the crop to:

- **All pages**, for consistent margins across a document.
- **The page you are looking at**, for a one-off fix.
- **Pages you choose by number**, such as `1-4, 9`, when only some pages need it.

The same margins are applied to every page you choose, so if page sizes differ across the document, check the result on each type of page.

## Setting exact margins

Dragging the box is quick, but it is not precise. Typing a percentage for each side gives repeatable results. For a scan with a consistent border, a few percent trimmed from every side often removes the dark scanner edge without cutting into the content. Keep a little breathing space; cropping too tightly makes text look cramped and risks clipping the edge of a character.

## Will the file get smaller?

No. Because the hidden content remains in the file, its size stays about the same. If the goal is a smaller file, use [Compress PDF](/compress-pdf) afterwards, or read [how to compress a PDF for email](/guides/compress-pdf-for-email).

## Good uses for cropping

- **Remove scanner borders** before sharing or printing.
- **Cut off a repeated header or footer** in a handout.
- **Focus on one figure or table** for a slide or report.
- **Make margins uniform** across pages scanned slightly off-centre.
- **Prepare pages for printing** where a narrower area fits the paper better.

## Cropping and what comes next

If you want to print several pages on one sheet, crop first so the margins do not waste space, then use [multiple pages per sheet](/multiple-pages-per-sheet). If you are also fixing orientation, [rotate](/rotate-pdf) first so the crop box matches how the page reads.

## Check the result

Open the cropped file and look at the pages where text sits closest to the edge. Check first and last pages in particular, and any page with a different size. If the content is cut off, go back and reduce the trim.

## Summary

1. Cropping hides the outside area; it does not delete it.
2. Use Redact PDF when information has to be removed for good.
3. Apply the crop to all pages, the current page or chosen pages.
4. File size stays about the same, so compress separately if needed.
