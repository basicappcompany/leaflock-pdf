Neo-Brutalism / Web Brutalism

Hard edges, visible structure, offset shadows instead of blur. Reads as unpolished on purpose — the opposite of generic SaaS, for better and worse.

Indie Web / Technical Aesthetic

Plaintext-adjacent, close to how documentation and terminals actually look. Cheap to build, credible to a technical audience, least "designed."

Bento Grid / Micro-SaaS Aesthetic

Rounded cards of varying size in one grid, soft depth, generous spacing. The current default language of funded, polished-looking software.
